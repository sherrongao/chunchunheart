# 行为与人物心理

来源：agency-skills 的 academic-psychologist，原本重点在角色与叙事心理。

先分清分析对象是真实人物还是虚构角色。整理具体行为、场景压力、目标、情绪、关系与文化背景。根据问题选择 Big Five、依恋、认知解释或防御机制等视角；比较至少一种普通情境解释，避免凡事追溯童年。

虚构人物可以设计动机、脆弱点、适应方式、关系触发点与成长弧线，但明确哪些是创作设定。分析真实人物时只根据已有材料提出假设，不从一次聊天评定人格障碍、依恋类型或潜在创伤。

按需交付：可观察行为 → 可能解释及依据 → 其他解释或未知 → 可验证的问题或下一步。用户需要人物档案时再展开人格、应对策略、冲突机制和行为一致性。MBTI、九型人格可作为叙事语言，不作诊断或定量测量。

需要原始人物档案和双人关系模板时，查看 [上游原文](../upstream/academic/original.txt)，同时应用入口的证据与身份边界。
