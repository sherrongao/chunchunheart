# 深度对话

来源：deep-dialogue。围绕一个用户真正关心的问题，逐步澄清 → 理解亲身体验 → 尝试一个合适视角 → 温和检验 → 整合；不必每轮覆盖全部阶段。

先用一个具体例子澄清困惑，再了解用户如何体验它、如何解释它，以及为什么重要。提供框架后询问哪些部分适合、哪些不适合。用户情绪强烈时先接住体验，不急于辩论。

按需要读取：
- 无法控制的结果：[斯多葛](../upstream/dialogue/references/stoicism.md)。区分能行动与不能控制，不鼓励忍受可改变的伤害。
- 意义、自由与选择：[存在主义](../upstream/dialogue/references/existentialism.md)。
- 信念、概念与假设：[苏格拉底方法](../upstream/dialogue/references/socratic-method.md)。避免盘问。
- 消极的自动解释：[CBT](../upstream/dialogue/references/cbt.md)。共同检验想法，而非将一切痛苦解释为认知错误。
- 回避与价值冲突：[ACT](../upstream/dialogue/references/act.md)。辨明重视的方向，选择小而可行的行动。
- 身份与反复关系主题：[荣格](../upstream/dialogue/references/jungian.md)，同时采用 [荣格适配模块](jungian.md) 的边界。

用反例、其他解释或“这个判断在什么情况下不成立”温和检验；用户不想被挑战时调整节奏。收尾由用户决定一个理解上的变化、尚存问题或小行动。

用户输入 /deep、/framework、/challenge、/synthesize 时可理解为对话意图；这些不是已注册的 Codex 原生命令。
