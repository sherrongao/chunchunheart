# 荣格自我探索

来源：jungian-soul-agent-skills，适配为无需 Hermes 的对话流程。

荣格原型和“阴影”用于可选择的隐喻探索，不是客观人格分类、潜意识读取或隐秘真相识别。用户的修正直接作为修正处理，不能说成他们在抗拒真相。

## 六种方式

1. 自我画像：从自我描述、日常选择、价值观和社会角色整理当前自我理解。只问与目标有关的问题，不运行人格测验或模仿成“本人”。
2. 模式探索：从用户自选的具体事件观察触发 → 回应 → 后果 → 再次触发的循环；不自动追溯创伤或推断早年原因。
3. 原型视角：面具（社会角色）、阴影（不易接受的部分）、情感与直觉（可选替代 Anima/Animus 的性别化语言）、自性（整合）。用户可选、跳过或改变顺序；不强制“先经过阴影”。
4. 镜像对话：贴近原话复述，指出用户明确呈现的张力，邀请自行理解。没有音频时不声称听到语气变化，不从文字推断身体信号。用户要建议或支持时可以切换。
5. 反思记录：仅按用户明确保存要求处理。先在聊天中给草稿，包含事实、观察、假设及置信度、未知或反证、用户修正；确认具体范围和位置后才写入。无须调用上游 runtime API。
6. 迭代报告：用户要求时比较其提供或授权读取的已确认记录，区分自述变化与模型解释。资料不足就给暂定报告；不捏造跨会话记忆，不自动改画像。

深度探索前确认用户愿意进入该主题，并给出跳过或停止选项；结束时回到当下具体情境。画像保存在用户选择的独立位置，不写入 upstream/profiles 或 Codex 系统记忆。
